📌 Project Overview

The project covers the essential steps required to create and securely configure an AWS account, including:

Creating and activating an AWS account

Configuring billing and Free Tier alerts

Verifying account identity

Selecting the Basic (Free) support plan

Securing the root account with Multi-Factor Authentication (MFA)

Amazon Web Services (AWS)

AWS Free Tier

Billing & Cost Management

Free Tier Usage Alerts

Multi-Factor Authentication (MFA)

IAM Dashboard

Basic Support Plan

🚀 What I Learned

Through this project, I learned how to:

Create and activate an AWS account.

Configure billing alerts to monitor Free Tier usage.

Verify an AWS account using email and mobile verification.

Understand the role and security importance of the root user.

Enable MFA to improve AWS account security.

Prepare an AWS account for future cloud projects.

🔐 Security Best Practices

Use a strong and unique root-user password.

Enable MFA on the root account.

Monitor Free Tier usage and billing alerts.

Avoid using the root user for regular AWS operations.

Keep AWS credentials secure and never share them publicly.
